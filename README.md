# abraflexi_pattern_library
Funkčné bloky volaní do a z abraflexi


PREDLOHA ZÁPISU
### Blok: Vytiahnutie všetkých vystavených faktúr za posledný mesiac (Fakturoid)

**Kedy toto použiť:** Keď potrebujem získať zoznam faktúr pre reporty, ale chcem len tie, ktoré boli reálne vystavené (nie koncepty) a spadajú do aktuálneho mesiaca.

**Skopírovaný JSON z Make modulu:**
{
    "sub": "search",
    "designer": {
        "x": 300,
        "y": 0
    },
    ... (tu jednoducho vložíš to, čo si skopíroval cez Ctrl+C z Make) ...
}
